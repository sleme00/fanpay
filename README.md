# FanPay веб-аналитика

Веб-приложение помогает собирать собственную базу объявлений, делать снапшоты
и сравнивать категории по спросу и ценам. Данные вводятся вручную (FanPay API
пока не подключён), поэтому можно добавить любую игру и нужные категории.

## Быстрый старт (Windows CMD, одна команда)

Открой CMD в папке проекта и запусти:

```bat
run.cmd
```

Скрипт создаст виртуальное окружение, установит зависимости и запустит приложение.

## Как пользоваться

1. На главной странице добавь свою игру.
2. Открой игру и добавь категории (например, валюта/услуга/предмет).
3. Добавляй объявления с ценами и продажами.
4. Нажми «Сохранить снапшот», затем «Анализировать».

## Ручной запуск

```bash
python -m venv .venv
```

Активировать окружение:

- Windows CMD:

```bat
.venv\Scripts\activate.bat
```

- Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

- Mac/Linux:

```bash
source .venv/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запуск приложения:

```bash
python -m fanpay_bot.web_app
```

Откройте в браузере: `http://localhost:8000`.

## Заметки

По умолчанию данные хранятся локально в SQLite (`fanpay_bot/data/snapshots.db`).
Если база пустая, будут загружены sample-данные из `FANPAY_SAMPLE_DATA`.
